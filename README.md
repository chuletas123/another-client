# Another Client

Repositorio privado de distribución de Another Client para Windows x64.

Los paquetes completos del cliente se adjuntarán a **GitHub Releases**. El historial Git contiene documentación y metadatos de las versiones.

## Versión preparada

El paquete actual es **alpha 1.2**, con la recuperación de los atajos de captura y grabación. Su inventario y huellas están en [releases/alpha-1.2.json](releases/alpha-1.2.json).

La integridad del paquete está comprobada. Sigue pendiente la prueba manual de los atajos y el guardado en esta versión. Todavía no se ha publicado una Release.

## Instalador y actualizaciones

El instalador y el actualizador están pendientes de implementación. [Distribución](docs/distribucion.md) describe cómo usar este repositorio privado con el VPS, conservando el acceso a GitHub en el servidor.

El JSON de esta versión es un inventario; todavía no es un canal de actualización firmado ni activa descargas en el cliente.
